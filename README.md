# BlogSpace · Frontend

The React frontend for BlogSpace, a full-stack blogging platform.

## Features

- Browse, search and read blog posts
- Write and edit posts
- Comments
- Sign up, log in and Google login
- User profile and personal dashboard
- About and contact pages, and light and dark themes

The backend for this app is in [blogspace-2](https://github.com/aksharaagarwal21/blogspace-2).

## Tech stack

React (Create React App) · React Router · Axios · date-fns · react-hot-toast

## Run locally

```bash
npm install
npm start
```

The app calls `http://localhost:5000/api` by default. Set `REACT_APP_API_URL` to use a different API.
